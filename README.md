# Soundside.ai Examples

Usage examples and sample projects for the [Soundside MCP API](https://soundside.ai).

## Examples

| Example | Description |
|---------|-------------|
| [image-generation](image-generation/) | Generate images across all providers |
| [image-to-video](image-to-video/) | Turn an image into a video with Veo or Luma |
| [tts-voiceover](tts-voiceover/) | Add TTS narration to a video |
| [multi-clip-composition](multi-clip-composition/) | Trim, concat, and grade multiple clips |
| [provider-comparison](provider-comparison/) | Side-by-side provider output comparison |

## Setup

```bash
pip install agentmail  # for inbox handling examples
export SOUNDSIDE_API_KEY=your_key_here
```

Or use the [OpenClaw skill](https://github.com/soundside-ai/openclaw-skill) for agent-native access.
